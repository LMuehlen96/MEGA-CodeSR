# MEGA-CodeSR

**Schockraum- & Reanimationsdokumentation** als offline-fähige Single-File-Web-App (PWA).
Grundlage: (PR_E-)AUD²IT-Mega-Code-Schema (Gröning et al., Notfall Rettungsmed 2022).

**Live:** https://LMuehlen96.github.io/MEGA-CodeSR/

## Nutzung auf dem iPhone
Live-URL in Safari öffnen → Teilen → **„Zum Home-Bildschirm"**. Danach läuft die App wie eine App, auch offline. Alle Daten bleiben ausschließlich lokal im Browser (localStorage); es werden keine Daten an einen Server gesendet.

## Umfang (Kurz)
Präklinische Reanimationsabfrage · eCPR-/ECMO-Pfad · geführter Ablauf PR_E-AUD²IT (TTO I–III) · Live-Tracker mit ERC-Empfehlungen · drei Live-Timer · Perfusor- & Lyse-Rechner · wischbares Postreanimations-Panel · Reanimationsregister-Erfassung (Schockraumphase) · PDF-/CSV-Export (offline erzeugt).

## Wichtiger Hinweis
Prototyp – **kein Medizinprodukt**. Dosierungen sind Orientierung; die **lokale SOP hat Vorrang**. Keine Speicherung langfristiger Patientendaten (nur Schockraumphase, lokal).
