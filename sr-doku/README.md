# SR-Doku

Allgemeine **Schockraumdokumentation** nach dem (PR_E-)AUD²IT-Basisalgorithmus mit SINNHAFT-Übergabe (Gräff et al., Notfall Rettungsmed 2024). Eigenständige App neben MEGA-CodeSR (Reanimation).

**Live:** https://LMuehlen96.github.io/MEGA-CodeSR/sr-doku/

iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Daten bleiben lokal im Browser. Protokoll als PDF (offline erzeugt) zum Teilen per Mail.

Prototyp – **kein Medizinprodukt**.
